# Contributing

Thanks for helping keep this list up to date!

## Adding a New Job

1. Go to **Issues** > **New Issue**
2. Use the **Add Job** template
3. Fill in: Company, Role, Location, Apply Link, Date Posted, Category
4. A PR will be created automatically

## Manual PR

If you'd prefer to submit a PR directly:

1. Fork this repo
2. Add the job to the appropriate section table in `README.md`
3. Follow the existing table format:

```
| Company | Role | Location | Category | [Apply](URL) | Mon YYYY |
```

4. Keep listings sorted by date (newest first)
5. Submit your PR

## Marking a Role as Closed

If an application window has passed, replace the Apply link with `Closed 🔒`.
